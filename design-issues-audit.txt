[BUG-20] stagger-children sets opacity:0 permanently if motion is reduced
  File    : src/app/globals.css  (lines 186-197)
  Problem : .stagger-children > * sets opacity: 0 as base. If a user has
            prefers-reduced-motion: reduce set, the animation won't run and
            elements stay permanently invisible.
  Fix     : Add @media (prefers-reduced-motion: reduce) block:
            .stagger-children > * { opacity: 1; animation: none; }

[BUG-21] animate-slide-up causes flash of invisible content on SSR
  Files   : Multiple pages -- admin, user, driver dashboards
  Problem : animate-slide-up starts at opacity:0. In Next.js SSR the initial
            HTML has opacity:0 before hydration triggers the animation. On slow
            connections this produces a flash of invisible content (FOIC).
  Fix     : animation-fill-mode: both is already set (good). Additionally add
            a noscript-safe fallback or wrap in a client-only animation trigger.
